### knowledge/pre-send-read.md (Skill: Pre-send read, file)

```md
# Pre-send read

## When to use
Before any message goes to a prospect, including every follow-up.

## Inputs
The draft, the recipient, the source for each fact about them, and the opt-out list.

## Steps
1. Mark every sentence in the draft that states a fact about the prospect or their company.
2. Under each marked fact, paste the source line you can quote and say where it came from.
3. Cut any fact with no quotable source. Do not fill the gap with a guess.
4. Check the recipient against the opt-out list. If they are on it, stop and say so.
5. Write one line on why this matters to this person today. If you can't, the verdict is DON'T SEND.
6. Count today's sends. If the daily send limit is reached, hold the draft for tomorrow.
7. Show me the verdict, the draft and the sources. Send only after I say yes to this draft and recipient.

## Validate
Every fact has a quoted source, the recipient is not opted out, and today's sends are under the limit.

## Returns
First line: READY, FIX or DON'T SEND. Then the draft, then one quoted source under each fact.

## Requires approval
send: ask me and wait for my yes on this exact draft and recipient before anything goes out.
```

### Routine: Follow-up cadence

```text
Set up a task: Every weekday at 9, run Follow-up cadence.
Steps:
1. List prospects with no reply 5 days after my opening message, or 10 days after my first follow-up.
2. Drop anyone who replied, asked me to stop or is on the opt-out list. Opt-outs are permanent.
3. Drop anyone who already got two follow-ups and mark them closed.
4. For each one left, find something new since my last message, with a source you can quote.
5. If nothing is new, draft nothing and write skip. Never send a "just checking in" note.
6. Otherwise draft one short follow-up built on the new fact, and run pre-send-read on it.
7. Hold the drafts for my yes. Send each only after I approve that draft. Stop at the daily send limit.
Needs my approval first: send: each follow-up waits for my yes on that exact draft and recipient. Drafting needs no yes; sending does.
If the task can't ask me, it stops and tells me instead.
```

## Install steps

1. In ChatGPT, create a new GPT and open Configure.
2. Set the Name. Paste the description into Description.
3. Paste your personality into Instructions. The hard limit is 8,000 characters.
4. Add the four conversation starters.
5. Upload each skill file under Knowledge.
6. Turn on only the Capabilities your skills need.
7. Add Actions only if a skill needs them. Mark every write action consequential (see the Actions note).
8. Say the memory sentence in a chat with your GPT.
9. Say each routine sentence. verify: whether your plan includes Tasks.
10. Choose who can use it: only you, anyone with the link, or the GPT Store. Check that nothing private is in it first.
